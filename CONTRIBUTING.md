# Как вести разработку · Contributing

> **EN.** This guide is in Russian. In short: run `go run ./cmd/gridlume dev`, keep every visible string in
> `web/src/i18n/{ru,en}.json`, use design tokens only, and run the checks below before a pull request.
> Issues are welcome in English; outside pull requests wait for a contributor agreement (CLA).

Проект пока пишется владельцем; чужие pull request'ы начнём принимать после подключения CLA
(соглашения участника) — см. [`docs/decisions.md`](docs/decisions.md), раздел «Лицензия».

## Запуск

Нужны Go 1.26+ и Node.js 24+.

```bash
cd web && npm ci && cd ..
go run ./cmd/gridlume dev
```

Откройте http://127.0.0.1:7420. `gridlume dev` запускает ядро и Vite вместе: API работает сразу,
интерфейс обновляется при сохранении файлов.

Сборка в один файл с встроенным интерфейсом:

```bash
cd web && npm run build && cd ..
go build -o bin/gridlume ./cmd/gridlume
```

## Правила

- **Ни одной строки текста в коде.** Всё видимое — ключи в `web/src/i18n/ru.json` и `en.json`,
  сразу на обоих языках. Тест проверяет, что в компонентах нет русского текста и что ключи совпадают.
- **Дизайн — только из токенов** `web/src/design/tokens.css`. Новый цвет, отступ или размер — сначала в токены,
  потом в компоненты.
- **Длинные объяснения — в подсказки** (`data-tip` / `tip`), на экране — коротко.
- **Горячие клавиши работают в любой раскладке.** Сочетание сравнивается по *физической* клавише
  (`KeyboardEvent.code`: `KeyF`, `Slash`), а не по введённому символу (`KeyboardEvent.key`): в русской
  раскладке клавиша F печатает «а», а «/» — «.». Все сочетания объявлены в одном месте —
  `web/src/hotkeys.ts` (`is(e, 'fit')`), новые добавляются туда же. Тест проверяет каждое сочетание в английской
  и русской раскладке и не пропускает сравнения `e.key === …` в компонентах.
- **Каждое действие, которое что-то меняет,** — с уровнем риска, планом, подтверждением и записью в журнал.
- **Бюджеты:** первая загрузка интерфейса ≤ 400 КБ (gzip), ядро ≤ 50 МБ памяти — проверяются в CI.
- **Карточка узла ничего не обрезает «…».** Расширить карточку нельзя, поэтому всё, что на ней написано, видно
  целиком: она растёт по ширине под содержимое (до 420 px, дальше — перенос), а виды узлов с живыми цифрами
  заранее шире, чтобы строка цифр помещалась. Не нужно на карточке — не показываем (подробности — в панели узла),
  но не режем.
- **Решения** записываем в `docs/decisions.md`: что решили и почему.

## Ветки и коммиты

- `main` — только проверенное. Работа — в ветках `stage/N-…` и коротких `feat/…`, `fix/…`.
- Pull request на этап: описание, снимки экрана, что проверено.
- Коммит — одно законченное изменение, сообщение по-английски в повелительном наклонении
  («Add agent enrollment»), тело — зачем.
