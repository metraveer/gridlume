# Макет и дизайн-система

Кликабельный макет без серверной части: демо-данные, одна карта с входом внутрь машин, живые связи, панель узла,
подтверждение опасного действия, добавление машины. Русский и английский переключаются кнопкой в шапке.

| Файл | Что внутри |
|---|---|
| `index.html`, `app.js` | макет главного экрана: данные, карта, уровни, связи, карточки, подтверждения |
| `features/impact-path.js` | «что сломается, если…» и путь запроса посетителя |
| `features/problems.js` | строка состояния, центр проблем, советы |
| `features/drawer.js` | нижняя панель: события, логи, терминал, история за сутки |
| `features/palette.js` | быстрые команды (Ctrl+K) |
| `features/discovery.js` | добавление: агент, поиск в сети, вручную; первый запуск (`?empty=1`) |
| `features/inspector-extras.js` | резервные копии и содержимое контейнера в карточке |
| `features/pages.js` | экраны: все узлы, журнал, пароли, уведомления, настройки |
| `features/polish.js` | мини-карта, «только проблемы», сворачивание мест |
| `features/changes.js` | «что изменилось перед сбоем», заметки, история настроек с «было / стало» |
| `features/layers.js` | слои: кто за кем присматривает, питание и ИБП, что видно из интернета |
| `scroll.js` | тонкие скроллбары и затухание края, когда есть что листать |
| `design-system.html` | цвета, шрифты, отступы, компоненты |
| `tokens.css` | все дизайн-токены — единственный источник цветов, размеров и шрифтов |
| `components.css` | компоненты, собранные только из токенов |
| `i18n.js` | словари RU/EN и всплывающие подсказки |
| `icons.js` | набор иконок |

## Как открыть

Браузеры не дают скриптам работать со страницей, открытой как файл, поэтому нужен простой локальный сервер:

```bash
python -m http.server 5180 --directory design/mockup
```

Затем откройте http://localhost:5180 (макет) и http://localhost:5180/design-system.html.

## Что попробовать

- Дважды щёлкнуть по машине (или нажать «›» на ней) — зайти внутрь и увидеть контейнеры. Наверх — крошки в шапке или Esc.
- Нажать на узел — справа откроются подробности. Перетащить узел — схема перестроится.
- Колесо мыши — масштаб, перетаскивание пустого места — сдвиг, `/` — поиск.
- Зайти в `gridman.example`, выбрать `gridman-api` → «Перенести на другую машину» — пример подтверждения опасного действия.
- «Добавить» — как подключается новая машина.
- Связи живые: точки бегут в сторону передачи, на линии — «идёт / должна быть». Жёлтые линии — проблема.
  Наведите на линию — сводка; нажмите — панель связи: три скорости, график за час, задержка, потери, события и объяснение.
- Выберите `postgres` → «Показать на схеме» в блоке «Если остановится» — подсветится всё, что пострадает.
- «Путь запроса» над схемой — как посетитель доходит до gridman.example и сколько занимает каждый шаг.
- Красная плашка «Проблем: 6» в шапке — что сейчас не так и советы. Нажмите на проблему — схема перейдёт к ней и откроет логи.
- Нижняя панель: события, живые логи выбранного узла, терминал машины, история за сутки (перетащите ползунок — схема покажет прошлое).
- `Ctrl+K` или поиск в шапке — быстрые команды: «перезапустить api», «postgres», «путь».
- «Добавить» → «Найти в сети» — поиск устройств; `?empty=1` в адресе — экран первого запуска.
- Слева: все узлы списком, журнал действий с откатом, пароли (в макете подходит любой мастер-пароль), правила уведомлений, настройки.
- «Только проблемы», стрелка у названия места (свернуть), мини-карта в правом нижнем углу.
- Выберите `ffmpeg-worker` или камеру — блок «Что изменилось перед этим»: изменение за несколько минут до сбоя, «Сравнить» и «Откатить». Там же заметки и история настроек.
- «Слои» над схемой: присмотр (кто за кем следит), питание (ИБП, план при отключении света — откройте узел «ИБП»), что видно из интернета (открытые порты и риски).
- Экран «Уведомления» слева: блок «Без лишнего шума» и пример сообщения в Telegram. В центре проблем у камеры — «объединено 3 сигнала».
