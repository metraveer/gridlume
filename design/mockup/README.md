# Макет и дизайн-система

Кликабельный макет без серверной части: демо-данные, три вида схемы, панель узла, подтверждение опасного
действия, добавление машины. Русский и английский переключаются кнопкой в шапке.

| Файл | Что внутри |
|---|---|
| `index.html`, `app.js` | макет главного экрана |
| `design-system.html` | цвета, шрифты, отступы, компоненты |
| `tokens.css` | все дизайн-токены — единственный источник цветов, размеров и шрифтов |
| `components.css` | компоненты, собранные только из токенов |
| `i18n.js` | словари RU/EN и всплывающие подсказки |
| `icons.js` | набор иконок |

## Как открыть

Браузеры не дают скриптам работать со страницей, открытой как файл, поэтому нужен простой локальный сервер:

```bash
python -m http.server 5180 --directory design/mockup
```

Затем откройте http://localhost:5180 (макет) и http://localhost:5180/design-system.html.

## Что попробовать

- Переключить виды **Сеть / Сервисы / Места** в шапке.
- Нажать на узел — справа откроются подробности. Перетащить узел — схема перестроится.
- Колесо мыши — масштаб, перетаскивание пустого места — сдвиг, `/` — поиск.
- В виде «Сервисы» выбрать `gridman-api` → «Перенести на другую машину» — пример подтверждения опасного действия.
- «Добавить» — как подключается новая машина.
- Связи живые: точки бегут в сторону передачи, на линии — «идёт / должна быть». Жёлтые линии — проблема.
  Наведите на линию — сводка; нажмите — панель связи: три скорости, график за час, задержка, потери, события и объяснение.
